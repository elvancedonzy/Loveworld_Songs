How to use:
  1. Open a supported page in Chrome
  2. Click the ♪ button (bottom-right corner)
  3. Review/adjust section labels if needed
  4. Click "Copy for ProPresenter"
  5. In ProPresenter: File → Import → Text from clipboard
  6. Set: Slides delimited by Line Break, 2 delimiters
  7. Click Import — groups auto-created!
